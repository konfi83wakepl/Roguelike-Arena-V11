Roguelike Arena V11 — Short Description
Roguelike Arena V11 is a fast, turn-based roguelike shooter where you face waves of enemies, collect power-ups, and use grenades and weapons to survive procedurally generated arenas. The game pairs a clear, character-based visual style with tight tactical combat and short, replayable missions.

Key Features
Turn-based combat with one action per turn; every move and shot matters.
Procedurally generated maps for fresh layouts each mission.
About 40 enemies per mission across varied types: Grunt, Shooter, Fast, Tank.
Grenades with flight animation and 3×3 explosions — two grenades per mission; throwing consumes your action for the turn.
Corpses and drops — killed enemies leave corpses (c) that can sometimes hide pickups.
Progression and scaling — earn frags to level up, collect power-ups (medpack, quad, haste, mega), and face tougher enemies as you clear missions.
Save and load support, including persistent stats like times cleared and grenade count.
Controls
Movement: Arrow keys or numpad (1–9)
Aim: SPACE to enter aim mode; use arrows to position target
Fire / Confirm: ENTER
Throw Grenade: G (only in aim mode; consumes a shot)
Reload: R
Look Mode: L to inspect tiles and entities
Doors: O open, C close, T toggle (T works in aim mode)
Save / Load: F5 save, F9 load
Why Play
Quick sessions ideal for short bursts of gameplay.
Tactical depth from limited actions, ammo management, and grenade timing.
High replayability thanks to random maps, varied enemy mixes, and item drops.
Retro-clear presentation with modern effects like projectile animations and explosions.
Build Contents and Tips
Included: Java Swing build (class/JAR), optional sound files (sfx1.wav–sfx7.wav), and an XML savegame file. Tips: Conserve shots, use grenades on clustered enemies, prioritize medpacks and mega health, and check corpses for hidden drops.
